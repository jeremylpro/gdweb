This page provides a technical reference for the audio subsystem in `gdweb`. It covers the asset loading pipeline, the implementation of the `AudioClass` manager, and the specific roles of background music and sound effects.

## Audio Lifecycle Overview

Audio assets are managed through a centralized `AudioClass` which wraps Phaser 3's Web Audio API implementation. The lifecycle begins in `BootScene.js`, where files are queued for loading, and continues in `GameScene.js` where the `AudioClass` handles playback, volume control, and real-time frequency analysis.

### Asset Loading

All audio files are loaded during the `preload` phase of the `BootScene`.

| Asset Key | File Path | Format | Role |
| --- | --- | --- | --- |
| `stereo_madness` | `assets/StereoMadness.mp3` | MP3 | Main background music (Level 1) |
| `explode_11` | `assets/explode_11.ogg` | OGG | Player death/collision SFX |
| `endStart_02` | `assets/endStart_02.ogg` | OGG | Level completion portal entry |
| `playSound_01` | `assets/playSound_01.ogg` | OGG | UI Button Click / Play |
| `quitSound_01` | `assets/quitSound_01.ogg` | OGG | UI Back / Quit |

## Audio Management Implementation

The `AudioClass` (instantiated as `this._audio` in `GameScene`) manages the active music stream and provides a global interface for triggering sound effects.

### Music Control

The system supports standard playback controls and volume normalization. The `_effectiveVolume` function applies a 0.8x multiplier to the user-defined volume to prevent clipping [src/systems/AudioManager.js17-19](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/AudioManager.js#L17-L19)

- **`startMusic()`**: Stops any existing instance, adds `stereo_madness`, sets it to loop, and initializes the Web Audio Analyser [src/systems/AudioManager.js20-31](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/AudioManager.js#L20-L31)
- **`fadeInMusic(duration)`**: Uses a Phaser Tween to transition volume from 0 to the effective volume [src/systems/AudioManager.js56-69](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/AudioManager.js#L56-L69)
- **`fadeOutMusic(duration)`**: Disables looping and tweens volume to 0 before stopping the track [src/systems/AudioManager.js71-83](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/AudioManager.js#L71-L83)

### Sound Effects

The `playEffect(soundKey, config)` method retrieves the current SFX volume from the scene and plays the requested key [src/systems/AudioManager.js85-90](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/AudioManager.js#L85-L90)

## Audio Metering Subsystem

The `AudioClass` includes a real-time metering system that analyzes the master volume output to drive visual effects in the game world (e.g., pulsing objects in the `Level` class).

### Technical Implementation

1. **Setup**: An `AnalyserNode` is created from the Phaser sound context and connected to the `masterVolumeNode`[src/systems/AudioManager.js93-98](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/AudioManager.js#L93-L98)
2. **Sampling**: In the `update` loop, `getFloatTimeDomainData` populates a `Float32Array` buffer [src/systems/AudioManager.js103](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/AudioManager.js#L103-L103)
3. **Peak Detection**: The system iterates through the buffer to find the absolute peak value, which is then normalized against the current effective volume [src/systems/AudioManager.js104-114](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/AudioManager.js#L104-L114)
4. **Decay Logic**: To prevent jittery visuals, the meter value decays by a factor of $0.92^{60 \cdot \Delta t}$ during quiet periods or responds to peaks with a $1.46^{60 \cdot \Delta t}$ growth factor [src/systems/AudioManager.js118-129](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/AudioManager.js#L118-L129)

### Audio-Visual Bridge

The calculated `_meterValue` is exposed via `getMeteringValue()`[src/systems/AudioManager.js136-138](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/AudioManager.js#L136-L138) This value is consumed by the `LevelClass` to scale decorative elements in sync with the beat.
