This page documents the foundational data structures and asset resolution utilities defined in `src/systems/GameState.js`. These systems manage the internal physical state of the player, define the collision primitives used throughout the level, and provide a pipeline for resolving textures from the game's sprite atlas.

## GameState Class

The `GameState` class serves as the central repository for the player's physical properties and movement flags. It is designed to be highly mutable, allowing the physics engine in `Player.js` to update state every tick (240Hz).

### Physical Properties and Flags

The class tracks vertical positioning, velocity, and environmental constraints.

| Property | Type | Description |
| --- | --- | --- |
| `y` | `Number` | Current vertical position in world coordinates. [src/systems/GameState.js9](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/GameState.js#L9-L9) |
| `yVelocity` | `Number` | Current vertical speed. Positive values usually indicate upward movement. [src/systems/GameState.js13](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/GameState.js#L13-L13) |
| `onGround` | `Boolean` | True if the player is currently supported by a solid surface. [src/systems/GameState.js15](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/GameState.js#L15-L15) |
| `onCeiling` | `Boolean` | True if the player is touching a ceiling (primarily used in Ship mode). [src/systems/GameState.js25](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/GameState.js#L25-L25) |
| `gravityFlipped` | `Boolean` | Indicates if gravity is inverted. [src/systems/GameState.js18](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/GameState.js#L18-L18) |
| `isFlying` | `Boolean` | True if the player is in "Ship" mode; false if in "Cube" mode. [src/systems/GameState.js19](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/GameState.js#L19-L19) |
| `isDead` | `Boolean` | Global flag to halt physics and trigger death sequences. [src/systems/GameState.js28](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/GameState.js#L28-L28) |

### State Lifecycle

The `reset()` method is used to initialize or restore the player to a default state upon level start or respawn. It defaults the player to a height of 30 units and clears all movement flags. [src/systems/GameState.js8-29](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/GameState.js#L8-L29)

## GameObject (Hitbox Schema)

The `GameObject` class represents a simplified collision primitive. Unlike Phaser's built-in physics bodies, these are lightweight objects used by the custom physics loop to calculate intersections with the player.

### Properties

- `type`: Categorizes the object (e.g., `solid`, `hazard`, `portal`). [src/systems/GameState.js57](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/GameState.js#L57-L57)
- `x`, `y`: The world coordinates of the object. [src/systems/GameState.js58-59](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/GameState.js#L58-L59)
- `w`, `h`: The width and height (extents) of the hitbox. [src/systems/GameState.js60-61](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/GameState.js#L60-L61)
- `activated`: A state flag used by triggers, pads, or portals to ensure they only fire once per contact. [src/systems/GameState.js62](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/GameState.js#L62-L62)

## Atlas Asset-Resolution Pipeline

The codebase uses a centralized texture atlas named `GJ_WebSheet`. To simplify sprite creation, `GameState.js` provides utility functions to resolve frames without manually specifying the atlas key every time.

### Key Functions

#### `findAtlasFrame(scene, frame)`

Iterates through the `ATLAS_KEYS` array (currently containing `"GJ_WebSheet"`) to check if a specific frame exists within the loaded textures. [src/systems/GameState.js34-43](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/GameState.js#L34-L43)

- **Input**: Phaser Scene context and the string name of the frame.
- **Output**: An object `{ atlas: key, frame: frame }` or `null`. [src/systems/GameState.js37-42](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/GameState.js#L37-L42)

#### `createImageFromAtlas(scene, x, y, frame)`

A wrapper for `scene.add.image` that handles three fallback cases:

1. If the frame exists in the `GJ_WebSheet` atlas, it creates the image using that atlas. [src/systems/GameState.js49](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/GameState.js#L49-L49)
2. If the frame is a standalone texture (not in an atlas), it creates the image directly. [src/systems/GameState.js50](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/GameState.js#L50-L50)
3. Returns `null` if the asset is missing. [src/systems/GameState.js51](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/GameState.js#L51-L51)
