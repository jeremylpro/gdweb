The `GJ_WebSheet` sprite atlas is the central graphical repository for **gdweb**. It consolidates player skins, object textures, UI elements, and particle frames into a single texture to optimize rendering performance and memory usage.

## Overview and Implementation

The atlas consists of two primary files loaded during the `BootScene` lifecycle:

1. **GJ_WebSheet.png**: The pixel data containing all sprites [assets/GJ_WebSheet.png1-32](https://github.com/brokemutt/gdweb/blob/1c1d347a/assets/GJ_WebSheet.png#L1-L32)
2. **GJ_WebSheet.json**: The manifest mapping logical frame names (e.g., `player_01_001.png`) to specific pixel coordinates, dimensions, and trimming data within the PNG [assets/GJ_WebSheet.json1-32](https://github.com/brokemutt/gdweb/blob/1c1d347a/assets/GJ_WebSheet.json#L1-L32)

The project uses Phaser 3's `TextureManager` to handle these assets. The atlas is identified globally by the key defined in `ATLAS_KEYS`[src/systems/GameState.js31](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/GameState.js#L31-L31)

### Data Flow: Asset Resolution

The system resolves frames through a centralized utility pipeline to ensure that objects can be created regardless of whether they reside in the main atlas or as standalone textures.

**Sources:**[src/systems/GameState.js31-52](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/GameState.js#L31-L52)

## Key Functions

### `findAtlasFrame(scene, frame)`

Iterates through the `ATLAS_KEYS` array to locate which atlas contains a specific filename.

- **Input**: Phaser Scene, String (filename).
- **Output**: Object `{ atlas, frame }` or `null`.
- **Location**: [src/systems/GameState.js34-43](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/GameState.js#L34-L43)

### `createImageFromAtlas(scene, x, y, frame)`

A wrapper for `scene.add.image` that abstracts the source of the texture. It prioritizes the atlas but falls back to the global texture cache for assets like the background or 9-slice panels.

- **Input**: Phaser Scene, Coordinates (x, y), String (frame name).
- **Behavior**: Checks atlas first via `findAtlasFrame`, then checks `scene.textures.exists`.
- **Location**: [src/systems/GameState.js46-52](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/GameState.js#L46-L52)
