The **Title Screen & UI** systems in `gdweb` manage the game's initial state, interactive menu elements, and on-screen overlays. This system utilizes a state-driven approach within `GameScene.js` to toggle between the menu and active gameplay, employing custom rendering techniques like 9-slice scaling for panels and physics-based "bouncy" animations for buttons.

## Menu State Management

The transition between the interactive title screen and the active level is controlled by the `_menuActive` flag [src/scenes/GameScene.js99](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/scenes/GameScene.js#L99-L99) When `true`, the scene renders the Geometry Dash logo, social links, and the main play button while keeping the level and player hidden.

### Key State Transitions

- **Initialization**: The scene starts with `_menuActive = true` and the level containers set to invisible [src/scenes/GameScene.js85-88](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/scenes/GameScene.js#L85-L88)
- **Game Start**: When the play button is clicked, `_startGame()` is invoked, setting `_menuActive = false` and triggering the `_slideIn` transition [src/scenes/GameScene.js100](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/scenes/GameScene.js#L100-L100)
- **Pause/Resume**: The game state is paused via `_pauseGame()`, which freezes the physics loop and displays the pause overlay [src/scenes/GameScene.js192](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/scenes/GameScene.js#L192-L192)

| Variable | Type | Role |
| --- | --- | --- |
| `_menuActive` | Boolean | Determines if the main menu UI is rendered and interactive. |
| `_slideIn` | Boolean | Controls the camera/ground slide effect when entering a level. |
| `_firstPlay` | Boolean | Tracks if the level is being entered for the first time in the session. |

## Interactive UI Components

The UI is built using assets from the `GJ_WebSheet` texture atlas.

### Bouncy Buttons (`_makeBouncyButton`)

Interactive elements such as the "Play" button and social links use a custom scaling animation to provide tactile feedback. The `_makeBouncyButton` function attaches pointer events to a Phaser Image:

1. **Pointer Over**: Tweens the scale to 1.1x of the original.
2. **Pointer Out**: Tweens the scale back to the base value.
3. **Pointer Down**: Tweens the scale to 0.9x.
4. **Pointer Up**: Triggers the provided callback and restores the "Over" scale.

### GJ Logo & Social Links

The main logo (`GJ_logo_001.png`) is positioned at the top center [src/scenes/GameScene.js109](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/scenes/GameScene.js#L109-L109) Download buttons for Steam, Google Play, and Apple are generated in a loop, each assigned a bouncy behavior and a `window.open` callback [src/scenes/GameScene.js122-142](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/scenes/GameScene.js#L122-L142)

## Visual Effects & Rendering

### 9-Slice Panel Renderer (`_drawScale9`)

To render UI panels of arbitrary sizes (like the Info or Pause popups) without stretching the borders, the system uses `_drawScale9`.

- **Mechanism**: It takes a source frame from the atlas and divides it into a 3x3 grid (corners, edges, and center).
- **Implementation**: It calculates the dimensions for the four corners (fixed size) and stretches the four edges and the center to fit the target width and height [src/scenes/GameScene.js210-230](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/scenes/GameScene.js#L210-L230)
- **Usage**: Used for the background of the `_buildInfoPopup` and the pause menu [src/scenes/GameScene.js164-170](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/scenes/GameScene.js#L164-L170)

### Glitter Particle Emitter (`toggleGlitter`)

The title screen features a "glitter" effect near the ground.

- **Emitter**: A Phaser Particle Emitter using the `square.png` frame [src/scenes/GameScene.js56-57](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/scenes/GameScene.js#L56-L57)
- **Logic**: The `toggleGlitter(on)` function enables or disables the emitter. It uses a custom `emitCallback` to randomize particle positions within a range relative to `_glitterCenterX` and `_glitterCenterY`[src/scenes/GameScene.js75-78](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/scenes/GameScene.js#L75-L78)

## Pause & Resume Logic

The pause system decouples the UI from the game simulation.

- **`_pauseGame()`**:

- Sets the scene's internal state to paused.
- Displays the pause overlay using `_drawScale9` for the panel.
- Invokes `this._audio.fadeOutMusic()` to dim the background track [src/scenes/GameScene.js192-200](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/scenes/GameScene.js#L192-L200)
- **`_resumeGame()`**:

- Hides the pause overlay.
- Restores the music volume via `this._audio.fadeInMusic()`.
- Resumes the `TICK_DELTA` physics accumulation [src/scenes/GameScene.js201-208](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/scenes/GameScene.js#L201-L208)
