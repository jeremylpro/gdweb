The `AudioManager` (implemented as `AudioClass`) is a centralized system responsible for music playback, sound effect (SFX) triggering, and real-time audio analysis. It leverages the Web Audio API to provide frequency metering, which is used to drive visual synchronization in the game environment.

## Audio Control Lifecycle

The `AudioClass` manages the global music state, including volume scaling and transition effects like fading. It interacts with the Phaser 3 `SoundManager` to execute playback commands.

### Key Functions

- **`startMusic()`**: Initializes and plays the primary background track (`stereo_madness`). It resets any existing music instance and triggers the audio analyser setup. [src/systems/AudioManager.js20-31](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/AudioManager.js#L20-L31)
- **`fadeInMusic(duration)`**: Stops existing music and uses a Phaser tween to linearly interpolate the volume from 0 to the user's effective volume over the specified duration. [src/systems/AudioManager.js56-69](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/AudioManager.js#L56-L69)
- **`fadeOutMusic(duration)`**: Gradually reduces the current music volume to 0 and stops the track upon completion. [src/systems/AudioManager.js71-83](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/AudioManager.js#L71-L83)
- **`playEffect(soundKey, config)`**: Plays a one-shot sound effect. It calculates the final volume by multiplying the requested volume with the scene's global `_sfxVolume`. [src/systems/AudioManager.js85-90](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/AudioManager.js#L85-L90)

### Volume Management

The system distinguishes between the raw volume and the "effective volume." The effective volume is hardcoded to a maximum of 80% of the user's setting (`0.8 * this._userMusicVol`) to prevent clipping and maintain headroom for SFX. [src/systems/AudioManager.js17-19](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/AudioManager.js#L17-L19)

## Audio Metering Sub-system

The `AudioClass` includes a peak-detection sub-system that analyzes the master audio output. This data is exposed via `getMeteringValue()` and is primarily used by `LevelClass` to scale decorative elements in time with the music.

### Implementation Details

1. **Analyser Setup**: The system creates a Web Audio `AnalyserNode` with an FFT size of 2048. It connects the Phaser `masterVolumeNode` to this analyser. [src/systems/AudioManager.js92-99](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/AudioManager.js#L92-L99)
2. **Peak Detection**: In the `update` loop, the system retrieves time-domain data into `_meterBuffer`. It iterates through the buffer to find the highest absolute sample value (the peak). [src/systems/AudioManager.js103-108](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/AudioManager.js#L103-L108)
3. **Decay Logic**: To ensure smooth visual transitions, the `_meterValue` does not strictly follow the raw peak. It uses a decay/response algorithm:

- **Attack**: If a significant peak is detected, the meter value increases by a factor of `1.46^tweenFactor`. [src/systems/AudioManager.js128](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/AudioManager.js#L128-L128)
- **Decay**: During lower volumes or sustained silence, the value decays by a factor of `0.92^tweenFactor`. [src/systems/AudioManager.js123](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/systems/AudioManager.js#L123-L123)

### Integration with Visuals

The `GameScene` calls `AudioManager.update(deltaTime)` every frame. [src/scenes/GameScene.js (implied)](https://github.com/brokemutt/gdweb/blob/1c1d347a/src/scenes/GameScene.js (implied)) The resulting `_meterValue` is then consumed by the level's rendering logic (e.g., `updateAudioScale` in `Level.js`) to pulsate objects.
