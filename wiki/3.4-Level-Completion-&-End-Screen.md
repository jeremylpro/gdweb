The level completion pipeline in `gdweb` is a multi-stage process that transitions the player from the active gameplay simulation to a celebratory state, culminating in the display of performance statistics and a navigational footer. This process involves physics state changes, visual effects, camera animations, and the instantiation of a 9-slice UI layer.

## Completion Pipeline Overview

The transition from gameplay to the end screen is orchestrated through four primary internal functions in `src/scenes/GameScene.js`.

### 1. Triggering the End Portal (`_triggerEndPortal`)

This stage is initiated when the player's horizontal position matches the end portal's location.

- **Physics Disabling**: The player's collision detection and movement logic are disabled via `this._player.playEndAnimation()`[[src/scenes/GameScene.js:588-592]]().
- **Animation**: The player is sucked into the portal using a Bezier curve animation defined in the `PlayerClass`[[src/player/Player.js:513-529]]().
- **Audio**: The `endStart_02.ogg` sound effect is triggered [[src/scenes/GameScene.js:591-591]]().

### 2. Level Complete State (`_levelComplete`)

Called after the player's suck-in animation completes.

- **State Management**: Sets `_isLevelComplete` to true and records the final time and jump counts [[src/scenes/GameScene.js:596-602]]().
- **Camera Transition**: Initiates `_endCamTween`, which pans the camera to center the end portal [[src/scenes/GameScene.js:603-611]]().
- **Progress Tracking**: Updates `_bestPercent` if the current run (100%) exceeds the previous best [[src/scenes/GameScene.js:601-601]]().

### 3. Visual Celebration (`_showCompleteText`)

A delayed sequence that adds visual flair to the screen.

- **Text Overlay**: Displays the "Level Complete" bitmap text using `bigFont`[[src/scenes/GameScene.js:621-628]]().
- **Particle Bursts**: Calls `emitWinBurst` multiple times to create randomized circle and square particle effects across the viewport [[src/scenes/GameScene.js:632-638]]().

### 4. End Layer Display (`_showEndLayer`)

The final stage where the statistics panel and buttons are rendered.

- **Panel Rendering**: Uses `_drawScale9` to create the standard Geometry Dash blue panel [[src/scenes/GameScene.js:646-646]]().
- **Stats Population**: Renders attempts, jumps, and time using `goldFont` and `bigFont`[[src/scenes/GameScene.js:655-675]]().
- **Star Animation**: Triggers a bouncy animation for the star icon and plays `highscoreGet02.ogg`[[src/scenes/GameScene.js:680-692]]().

| Stage | Function | Key Action |
| --- | --- | --- |
| **Trigger** | `_triggerEndPortal` | Disables player physics; starts Bezier suck-in. |
| **Logic** | `_levelComplete` | Records stats; pans camera to portal. |
| **Visuals** | `_showCompleteText` | Spawns "Level Complete" text and `emitWinBurst`. |
| **UI** | `_showEndLayer` | Draws 9-slice panel and interactive buttons. |

**Sources:**[[src/scenes/GameScene.js:588-692]](), [[src/player/Player.js:513-529]](), [[src/effects.js:51-93]]()

## Statistics and Best Percent Tracking

The system tracks three primary metrics during the level completion phase:

1. **Attempts**: Incremented every time `_resetGameplayState` is called [[src/scenes/GameScene.js:90-90]]().
2. **Jumps**: Accumulated in `_totalJumps` by listening for player jump inputs [[src/scenes/GameScene.js:95-95]]().
3. **Time**: Calculated as `_playTime` based on the physics `TICK_DELTA` accumulation [[src/scenes/GameScene.js:96-96]]().

### Best Percent Logic

The `_bestPercent` is updated during both death and completion. If the player dies, the percentage is calculated based on horizontal progress relative to the end portal's X position [[src/scenes/GameScene.js:570-575]](). Upon completion, it is hardcoded to 100 [[src/scenes/GameScene.js:601-601]]().

## End Screen UI Components

The End Screen is composed of several interactive and static elements layered on top of the `GameScene`.

### 9-Slice Panel (`_drawScale9`)

The background panel is procedurally generated using the `_drawScale9` utility, which takes a source frame (like `GJ_square02.png`), dimensions, and a corner offset to prevent texture stretching [[src/scenes/GameScene.js:646-646]]().

### Footer Buttons

The footer contains three main buttons managed by `_makeBouncyButton`:

- **Replay**: Calls `_resetGameplayState(true)` to restart the level immediately [[src/scenes/GameScene.js:705-705]]().
- **Menu**: Sets `_menuActive = true` and resets the camera to the title screen position [[src/scenes/GameScene.js:701-701]]().
- **Statistics/Share**: Placeholder for extended functionality [[src/scenes/GameScene.js:709-709]]().

### Visual Effects (Win Bursts)

The `emitWinBurst` function in `src/effects.js` creates a combination of:

1. **Circle Effect**: An expanding, filled circle with `Quad.Out` easing [[src/effects.js:56-56]]().
2. **Square Particles**: 25 particles using `square.png` with randomized speeds (520-920) and angles (0-360) [[src/effects.js:59-92]]().
