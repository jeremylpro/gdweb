This page documents the pipeline for transforming raw level data into interactive game objects. It covers the decompression of level strings, the mapping of key-value pairs to object properties, and the structural definitions that govern how objects behave and render within the world.

## Level Data Pipeline

Level data in `gdweb` follows a specific transformation path from a compressed string (stored in `assets/1.txt`) to a structured JavaScript object array.

### 1. Decompression & Decoding

The `parseLevel` function in `src/world/LevelLoader.js` handles the multi-stage decoding process:

1. **Base64 Normalization**: The input string is converted from a URL-safe Base64 format (replacing `-` with `+` and `_` with `/`) to standard Base64 `<FileRef file-url="https://github.com/brokemutt/gdweb/blob/1c1d347a/src/world/LevelLoader.js#L38-L43" min=38 max=43 file-path="src/world/LevelLoader.js">Hii</FileRef>`.
2. **Binary Conversion**: The Base64 string is decoded into a `Uint8Array``<FileRef file-url="https://github.com/brokemutt/gdweb/blob/1c1d347a/src/world/LevelLoader.js#L45-L47" min=45 max=47 file-path="src/world/LevelLoader.js">Hii</FileRef>`.
3. **Pako Inflate**: The binary data is decompressed using the `pako` DEFLATE algorithm `<FileRef file-url="https://github.com/brokemutt/gdweb/blob/1c1d347a/src/world/LevelLoader.js#L49-L49" min=49  file-path="src/world/LevelLoader.js">Hii</FileRef>`.
4. **Text Decoding**: The resulting bytes are decoded into a UTF-8 string via `TextDecoder``<FileRef file-url="https://github.com/brokemutt/gdweb/blob/1c1d347a/src/world/LevelLoader.js#L50-L50" min=50  file-path="src/world/LevelLoader.js">Hii</FileRef>`.

### 2. String Splitting

The decompressed string is delimited by semicolons (`;`). The first element contains level settings (background ID, ground ID, etc.), while subsequent elements represent individual game objects `<FileRef file-url="https://github.com/brokemutt/gdweb/blob/1c1d347a/src/world/LevelLoader.js#L53-L55" min=53 max=55 file-path="src/world/LevelLoader.js">Hii</FileRef>`.

## Object Parsing (`parseObject`)

Each object string consists of comma-separated key-value pairs. The `parseObject` function maps these numeric keys to human-readable properties used by the engine `<FileRef file-url="https://github.com/brokemutt/gdweb/blob/1c1d347a/src/world/LevelLoader.js#L8-L34" min=8 max=34 file-path="src/world/LevelLoader.js">Hii</FileRef>`.

### Key-Value Mapping Table

| Key | Property | Type | Description |
| --- | --- | --- | --- |
| **1** | `id` | Integer | The Object Definition ID (e.g., 1 for Block) |
| **2** | `x` | Float | World X coordinate |
| **3** | `y` | Float | World Y coordinate |
| **4** | `flipX` | Boolean | Horizontal sprite flip |
| **5** | `flipY` | Boolean | Vertical sprite flip |
| **6** | `rot` | Float | Rotation in degrees |
| **32** | `scale` | Float | Uniform scale factor |
| **21** | `color1` | Integer | Primary color channel ID |
| **22** | `color2` | Integer | Secondary color channel ID |

## Object Definitions (`OBJECT_DEFINITIONS`)

The `OBJECT_DEFINITIONS` constant in `src/world/LevelLoader.js` serves as a lookup table that assigns gameplay logic and visual metadata to the raw IDs parsed from the level data `<FileRef file-url="https://github.com/brokemutt/gdweb/blob/1c1d347a/src/world/LevelLoader.js#L69-L69" min=69  file-path="src/world/LevelLoader.js">Hii</FileRef>`.

### Definition Structure

Each definition entry can contain the following properties:

- **type**: A constant from `src/constants.js` (e.g., `OBJECT_TYPE2_SOLID`, `OBJECT_TYPE2_HAZARD`) defining collision behavior `<FileRef file-url="https://github.com/brokemutt/gdweb/blob/1c1d347a/src/world/LevelLoader.js#L71-L129" min=71 max=129 file-path="src/world/LevelLoader.js">Hii</FileRef>`.
- **frame**: The texture frame name from the `GJ_WebSheet` atlas `<FileRef file-url="https://github.com/brokemutt/gdweb/blob/1c1d347a/src/world/LevelLoader.js#L72-L72" min=72  file-path="src/world/LevelLoader.js">Hii</FileRef>`.
- **gridW / gridH**: The dimensions of the object in grid units (30px per unit) `<FileRef file-url="https://github.com/brokemutt/gdweb/blob/1c1d347a/src/world/LevelLoader.js#L73-L74" min=73 max=74 file-path="src/world/LevelLoader.js">Hii</FileRef>`.
- **hitboxScaleX / hitboxScaleY**: Multipliers used to shrink or grow the collision area relative to the sprite size `<FileRef file-url="https://github.com/brokemutt/gdweb/blob/1c1d347a/src/world/LevelLoader.js#L135-L136" min=135 max=136 file-path="src/world/LevelLoader.js">Hii</FileRef>`.
- **children**: An array of sub-sprites (often for color-tinted layers) `<FileRef file-url="https://github.com/brokemutt/gdweb/blob/1c1d347a/src/world/LevelLoader.js#L123-L126" min=123 max=126 file-path="src/world/LevelLoader.js">Hii</FileRef>`.

## Runtime Integration

When `LevelClass.loadLevel` is called in `src/world/Level.js`, it invokes `parseLevel` and passes the resulting array to `_spawnLevelObjects``<FileRef file-url="https://github.com/brokemutt/gdweb/blob/1c1d347a/src/world/Level.js#L58-L63" min=58 max=63 file-path="src/world/Level.js">Hii</FileRef>`.

The system then:

1. Iterates through the parsed objects.
2. Retrieves the definition from `OBJECT_DEFINITIONS` via `getObjectDefinition(id)``<FileRef file-url="https://github.com/brokemutt/gdweb/blob/1c1d347a/src/world/LevelLoader.js#L464-L472" min=464 max=472 file-path="src/world/LevelLoader.js">Hii</FileRef>`.
3. Calculates the world position and hitbox using `TILE_SIZE` (30px) `<FileRef file-url="https://github.com/brokemutt/gdweb/blob/1c1d347a/src/world/Level.js#L453-L470" min=453 max=470 file-path="src/world/Level.js">Hii</FileRef>`.
4. Places objects into spatial "sections" (400px wide) to optimize rendering and collision checks `<FileRef file-url="https://github.com/brokemutt/gdweb/blob/1c1d347a/src/world/Level.js#L527-L540" min=527 max=540 file-path="src/world/Level.js">Hii</FileRef>`.
